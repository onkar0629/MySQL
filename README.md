# 🐬 MySQL

A structured MySQL learning repository covering SQL from **fundamentals to advanced concepts**, with a focus on **Data Engineering** and **technical interview preparation**.

## 📚 Learning Approach

This repository is organized by **topic**, not by day. Each major topic contains explanations, worked examples, and hands-on practice.

```text
MySQL/
├── Learning/
├── Interview-Preparation/
├── Projects/
└── README.md
```

## 🎯 Goal

Build strong, practical MySQL skills for a **Junior / Associate Data Engineer** role, progressing from basic SQL to advanced querying, database design, performance tuning, and Data Engineering use cases.

## 🧭 Learning Path

- SQL Fundamentals
- Databases and Tables
- Data Types
- DDL, DML and DQL
- Filtering and Sorting
- Aggregate Functions
- GROUP BY and HAVING
- String, Numeric and Date Functions
- NULL Handling and Conditional Logic
- Joins
- Subqueries
- CTEs and Recursive CTEs
- Set Operations
- Window Functions
- Views and Temporary Tables
- Stored Procedures and Functions
- Triggers
- Transactions and Locking
- Constraints and Keys
- Indexes
- Execution Plans and Query Optimization
- Normalization and Database Design
- JSON in MySQL
- Partitioning
- Data Import and Export
- Real-World Data Engineering SQL
- Interview Preparation

## 📁 Topic Structure

Each topic will generally follow this pattern:

```text
Topic_Name/
├── README.md
├── examples.sql
└── practice.sql
```

## 🚀 Progress

Learning is built progressively from **basic → intermediate → advanced** while keeping interview relevance in mind.
