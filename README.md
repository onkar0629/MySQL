# 🐬 MySQL

A structured MySQL learning repository covering SQL from **fundamentals to advanced concepts**, with a focus on **Data Engineering** and **technical interview preparation**.

## 📚 Learning Approach

This repository is organized by **topic**, not by day. Each topic has its own folder containing the learning material, examples, and practice exercises.

## 📁 Topic Folder Structure

Every topic will follow the same structure:

```text
Topic_Name/
├── README.md       # Concepts and notes
├── examples.sql    # Worked examples
└── practice.sql    # Hands-on practice
```

Larger topics may contain additional subtopic folders where necessary.

## 🎯 Goal

Build strong, practical MySQL skills for a **Junior / Associate Data Engineer** role, progressing from basic SQL to advanced querying, database design, performance tuning, and real-world Data Engineering use cases.

## 🚀 Progress

Learning will progress from **basic → intermediate → advanced → Data Engineering**, with interview relevance maintained throughout.
